# 🌿 Prakriti Vegetable Supplier ERP

Production-grade B2B ERP platform for vegetable suppliers serving restaurants, cafes, hotels, caterers, and commercial kitchens.

## Tech Stack

### Frontend
- React
- Vite
- React Router
- Zustand
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

## Modules

- Customer Management
- Product Management
- Order Management
- Invoice Management
- Payment Management
- Reports
- QR Ordering
- OTP Verification
- WhatsApp Automation
- AI Assistant (Future)

## Project Structure

```
client/
server/
```

## Development

Client

```bash
cd client
npm install
npm run dev
```

Server

```bash
cd server
npm install
npm run dev
```
