# Operations Center UI & Performance Profiler — Documentation

## Operations Center Console (`EnterpriseOperationsCenter.jsx`)
Workspace located at `/observability` providing:
- **System Health Status Banner**: Displays overall health (`Healthy`, `Warning`, `Critical`) and uptime.
- **Metric Scorecards**: Real-time cards for Memory %, MongoDB Latency, Avg API Latency, Active Alerts.
- **Subsystem Inspector Tab**: Detailed status table for all 6 core ERP infrastructure platforms.
- **Live Telemetry Stream Tab**: Searchable table displaying structured logs with PII data masking.
- **Diagnostics Studio**: Button to run full on-demand system diagnostic suites.
